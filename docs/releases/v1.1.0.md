# Walmart Ads Trends v1.1.0

首次 GitHub 发布 / First GitHub release · 2026-11-08

应用基于 2026-10-24 的 V1.1.0 静态部署版。广告报表和产品映射表在浏览器内处理。

## 下载与部署

- `walmart-ads-trends-v1.1.0-static.zip`：已经构建的完整静态站。上传到网站目录并直接解压，让 `index.html`、`assets/` 和 `templates/` 位于该目录内。
- `SHA256SUMS.txt`：静态 ZIP 的 SHA-256 校验值。
- GitHub 的 `Source code` 下载：完整仓库，包含 `source/` 下的 React / TypeScript 源码、说明和截图。

不需要在服务器安装 Node.js。使用带末尾斜杠的网址访问，更新后按 Ctrl+F5 刷新。

## 看板功能

- 按 Item ID、品类、后台 SKU、SKU 和广告版位筛选分析。
- 8 项核心指标、版位饼图和柱状图、10 项指标趋势、排名与快速洞察。
- 日 / 周 / 月、自定义日期与多选对比。
- CSV 报表与映射表模板；保留字段顺序提示和版权备案页脚。

## English

Download the static ZIP for direct hosting. Extract its contents into your site directory; no Node.js or backend is required. Use a trailing-slash URL.

The application analyzes Walmart CSV reports locally in the browser, with item / SKU / category / placement filters, KPI cards, placement charts, trends, rankings and insights.
The repository also includes editable source, bilingual documentation, screenshots, templates and MIT license notices.
