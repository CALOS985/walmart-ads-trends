# Walmart Ads Trends v1.2.0

时间段对比与灵活 CSV 导入 · 2026-11-09

## 新增时间段对比

- 位于“Item ID 表现排名”上方，逐 Item 展开 10 项指标。
- 快捷比较近 3 / 7 / 30 天和之前相同天数，或最新完整自然月与上一个月；也支持两个自定义区间。
- 同时显示时间段 1、时间段 2、差值、变化率。上涨绿色 ↑、下跌红色 ↓；附上成本和效率解读。
- 默认对比全部 Item ID，支持搜索、全部展开 / 收起，可跟随上方商品 / 品类 / SKU 筛选，版位筛选生效。
- 日期独立设置，快捷区间以报表最新日期为基准。覆盖不足、区间天数不同、重叠、零基期、零分母和无记录均有明确处理。

## CSV 导入

- 按字段名识别报表与映射表，列顺序可以调整。
- 保留模板字段名称；缺少必需字段或重复字段会提示。
- 若报表有 Clicks，优先使用实际点击。比率根据区间汇总重新计算。

## 下载和升级

下载 `walmart-ads-trends-v1.2.0-static.zip`，在现有网站目录内直接解压覆盖，让 index.html、assets 和 templates 位于该目录顶层。
随后按 Ctrl+F5 刷新；必要时清除此页面的服务器 / CDN 缓存。无需服务器端 Node.js。
`SHA256SUMS.txt` 用于核对压缩包完整性。

## 验证

源码类型检查、12 项逻辑测试和生产构建通过；浏览器已验证打乱列序的样例导入、10 项指标、涨跌颜色、自定义区间和板块位置。
